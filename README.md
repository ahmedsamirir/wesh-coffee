# Wesh Coffee · preview website

Preview of the Wesh specialty coffee website (Degla, Maadi). English and Arabic, works on phone, tablet and desktop.

- `index.html` is the whole site (all pages)
- `fonts/` holds the brand fonts

This is a preview: orders, RSVPs and club sign-ups are not saved or sent, and prices, hours, the address and social handles are placeholders.

Live site (after GitHub Pages is switched on): https://ahmedsamirir.github.io/wesh-coffee/
